SOMNIA REACTIVITY PRECOMPILE × DREAMDEX EVENT CONTRACTS

Liquidity is a quoting commitment backed by an on-chain bond.

DreamDEX order books are sampled at discrete instants using Somnia validator-driven callbacks. When a maker breaches committed spread or depth, the bond forfeits pro rata to traders witnessed in that window.

What this deployment does, exactly. It measures and it records. It does not settle. A bond is recorded as forfeited and no trader is paid, because the payout path was cut under this project's own kill criteria when the submission window got short. Nothing here implies anyone was made whole.

THE VERDICT FUNCTION, RUN IN YOUR BROWSER

Not chain data. This runs the same pure evaluator the contract runs, on numbers you choose, so you can watch the states change. Move the spread past the committed bound.

Instant Reactive Sampling (Path R)

A subscription on the pool wakes the registry when the market emits. Validators invoke the handler as a synthetic transaction, it reads the book at that instant, and the sample is written on chain. Nobody sends a transaction to make it happen.

Zero-Trust Stranger Verification

The verdict is a pure function of a stored sample and a stored commitment, so anyone can re-derive it from a public RPC with a second implementation.

pnpm claim:verify

Witnessed Volume Settle

Designed and not deployed. The registry witnesses fills through the same subscription, so a forfeited bond could be split pro rata among the addresses it saw trading that window, with self-match rejection and a per-address cap. That path was cut under K10. The mechanism is in the design; it is not in this deployment, and no bond has been split.

Unfiltered Integrity (The Anti-Dashboard)

Gaps are recorded as NOT_SAMPLED and never folded into coverage. A window that was 90% unsampled is reported as a window that was 90% unsampled.
